# 動作分析アプリ試作

`Python` の標準ライブラリだけで動く簡易モックです。

## 起動

```bash
python3 app.py
```

ブラウザで `http://127.0.0.1:8000` を開くと、以下の画面を確認できます。

- ホーム
- 撮影画面
- 比較画面
- 保存一覧
- 設定

## 目的

- コーチが基準動画と選手動画を比較する流れを固める
- スライドで録画制御する UI イメージを確認する
- 本格実装前に必要画面と操作を整理する

## 補足

この試作はローカルで完結します。最初の段階ではサーバーは不要です。
将来的にアカウント管理、クラウド同期、複数端末共有が必要になった段階でサーバーを追加します。
